# Cinematic 3D Portfolio

A highly interactive, performance-driven 3D portfolio built with React, Three.js, and TypeScript. This project showcases a "cinematic" aesthetic with immersive WebGL environments, smooth scrolling, glitch effects, and advanced typography to create an award-winning user experience.

## ✨ Features

- **Immersive 3D Environments:** Powered by React Three Fiber (`@react-three/fiber`) and Drei (`@react-three/drei`).
- **Smooth Scrolling:** Fluid scroll experiences enabled by Lenis (`@studio-freight/lenis`).
- **Cinematic Animations:** High-performance UI animations built with Framer Motion (`framer-motion`).
- **Advanced Post-Processing:** Bloom, glitch, and neon glow effects utilizing `@react-three/postprocessing`.
- **Interactive Particle Systems:** Dynamic matrix rain and hacker text components.
- **Fully Responsive & Typed:** Built ground-up with TypeScript and designed for both desktop and mobile layouts.

## 🛠️ Technology Stack

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **3D Graphics:** [Three.js](https://threejs.org/) + [React Three Fiber](https://r3f.docs.pmnd.rs/getting-started/introduction)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

To run this project locally on your machine, follow these steps:

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/parthsuryawanshi0207-0207/Portfolio.git
   ```
2. Navigate into the project directory:
   ```bash
   cd Portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the Development Server

Start the Vite development server:
```bash
npm run dev
```
Open your browser and visit `http://localhost:5173` to view the portfolio.

### Building for Production

To create an optimized production build:
```bash
npm run build
```
The compiled static files will be located in the `dist` directory, ready to be deployed.
